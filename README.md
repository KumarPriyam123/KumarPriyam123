**MARL-MAPS** — *Multi-Agent Reinforcement-Learned, Memory-Augmented, Process-Supervised RAG*
<br><sub>NIT Delhi capstone · three-person team · ongoing</sub>

Standard RAG retrieves on a fixed schedule and pays for it in latency, tokens and
hallucinated intermediate steps. MARL-MAPS treats routing as a **Dec-POMDP** and trains
the agents to negotiate:

- **Learned routing policy** replaces rigid pass/fail retrieval gates — **91%** of redundant database searches eliminated
- **Role-scoped LoRA adapters** (Query / Judge / Answer) over a single frozen 7B base — **60%** less deployment VRAM than three separate models
- **Self-REF confidence calibration** — a continuous logit-extraction protocol scoring each step instead of a binary gate
- **HiPRAG process rewards** penalise hallucinated reasoning steps, not just wrong final answers — **+6%** multi-hop F1

Evaluated on HotpotQA over a 9,769-passage FAISS index, served through vLLM on a single T4.
